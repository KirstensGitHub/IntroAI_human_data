# Project overview
This dataset is part of ongoing research at the intersection of AI, social cognition, and human-AI interaction. This work is being conducted at the Princeton Neuroscience Institute spearheaded by Kirsten Ziman, along with Jack Thompson and Lily Weaver. 

# Methods
The data in this repository constitutes the highest quality data collected from online participants (via Prolific.com,  Cognition.run), filtered through a combination of participant sign-up requirements and post-collection quantitative analysis and data filtering.  Additional details about data curation and filtering methods will be made available in pending publications. For additional details before that time, please contact kz0108@princeton.edu.
